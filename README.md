# Angular + Ethers.js v6 Blockchain Integration

This repository demonstrates how to integrate **Ethers.js v6** with an **Angular** application for blockchain interaction on the **Sepolia testnet**, using **MetaMask** as the wallet provider.  

It includes examples for **reading & writing** blockchain data, sending and receiving test ETH, and **real-time event listening** from smart contracts.

---

## 🚀 Features

- **MetaMask Wallet Connection** – Connect and authenticate users via MetaMask.
- **Read Functions** – Retrieve blockchain data from smart contracts.
- **Write Functions** – Send transactions and update blockchain state.
- **Send & Receive Test ETH** – Interact with Sepolia testnet Ether.
- **Real-Time Event Listening** – Subscribe to and log smart contract events as they occur.

---

## 🛠 Tech Stack

- **Frontend:** Angular  
- **Blockchain Library:** Ethers.js v6  
- **Wallet:** MetaMask  
- **Network:** Ethereum Sepolia Testnet
